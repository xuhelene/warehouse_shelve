# 三维货架预览

启动现有 FastAPI 服务后访问 `/warehouse-preview`，首页也有“三维货架预览”入口。

```powershell
python -m apps.web_portal --port 8010
```

布局：C14、C15 背对背；C14 左侧和 C15/C16 中间为双向通道；第 1 列前方横向通道连接二者。第 45 列靠墙，无后方通道。C16 右侧灰色区域表示其他项目货架，无通道。三排的第 20—22 列底部两层均留空，上方三层保留。有效货位共 657 个。

业务坐标为 X 向右、Y 从门口向墙、Z 向上，原点为门口中央地面。当前均为示意单位：列宽 1、货架深 1.2、层高 1，货架起始 Y=2；C14/C15/C16 的中心 X 分别为 -2.4/-1.2/2.4。门口起点可在页面修改，刷新后恢复 (0,0,0)。起点范围 X∈[-5.4,3]，Y∈[0,2)。

页面支持空布局、固定演示库存、演示入库、演示拣货、旋转/缩放/平移、俯视、按层隐藏和编号定位。路径沿地面，高层目标通过货位高亮与层号识别。演示路线仅展示画线能力，不执行优化、不修改真实库存、不写入 results。

## 后续业务接入

复用本页或者通过 iframe 嵌入。渲染初始化成功后，页面内可调用 `window.warehousePreview.setData`，通过 `getSlots()` 获取货位编号及示意中心坐标，通过 `config.origin` 读取门口起点。以下坐标均使用业务坐标，无需转换 Three.js 坐标。

```javascript
window.warehousePreview.setData({
  mode: 'inbound', // inventory / inbound / outbound
  inventory: [{slot_id: 'C14-1-1', item_id: 'SKU-001', quantity: 10}],
  targets: ['C16-30-4'],
  paths: [[{x:0,y:0}, {x:0.6,y:0}, {x:0.6,y:31.5}, {x:0.6,y:0}, {x:0,y:0}]]
});
```

`setData` 整体替换显示快照；货位必须存在，目标模式须为 inbound 或 outbound，路径须为至少两个有限坐标点，按通道正交行走。路径点代表通道中的停靠位置，不是货架中心。库存数据由调用方按货位汇总，每条记录代表一个货位；示意尺寸替换为实测尺寸时，应同时调整场景几何和路径通道范围。

当前只提供前端显示接口，未接入库存文件或业务推荐求解结果。前端资源全部来自项目本地，无需外部 CDN。
